# 中文 AI 写作痕迹检查表

> 24 种模式，按检测可靠度分三级：🔴 高信度（组合出现几乎确定 AI 生成）、🟡 中信度、🟢 低信度（单独出现不足以判定，需组合）。
>
> 核心原则：**看密度和组合模式**，不因个别信号下结论。一篇文档中出现 5+ 个不同模式 → AI 生成概率极高。

---

## 🔴 高信度模式（组合出现 ≈ AI 生成）

### P1. 排比三连（Rule of Three）

AI 偏好把一切归纳为三要素。

**信号：**
- "不仅...而且...更..."
- "一方面...另一方面...此外..."
- "准确性、完整性和及时性"
- 每段/每节都有三个并列项

**示例：**
> ❌ 该系统不仅提高了数据处理效率，而且降低了运维成本，更保证了服务的稳定性。
> ✅ 该系统将数据处理速度提升了 3 倍，运维成本从月均 12 万降至 4 万。

### P2. 空泛过渡语（Hollow Transitions）

**高频词组：**
- 值得注意的是 / 需要指出的是 / 需要强调的是
- 总而言之 / 综上所述 / 总的来说
- 在此基础上 / 与此同时 / 不仅如此
- 具体而言 / 换言之 / 简而言之

**判定标准：** 全文出现 3+ 次不同空泛过渡语 → 高信度

### P3. 对称标题结构（Symmetric Headings）

AI 偏好"X与Y"对称标题。

**常见组合：**
- "现状与展望" / "挑战与机遇" / "问题与对策"
- "背景与意义" / "方法与结果" / "讨论与结论"
- 每个一级标题下都有恰好两个二级标题

### P4. 无数据空泛描述（Data-Free Claims）

**信号：**
- "取得了显著成效" / "获得了广泛应用" / "发挥了重要作用"
- "大幅提升" / "有效改善" / "显著降低"（无具体数字）
- "业界领先" / "国内首创"（无来源）
- 整篇文档没有一个具体数字

**判定标准：** 通篇无具体数据/数字/百分比/日期 → 高信度

### P5. 段尾总结句（Paragraph Kicker）

AI 每段末尾都习惯加一句总结。

**信号：**
- 每段最后一句都是对该段内容的概括
- "这表明..." / "这意味着..." / "这说明..."
- 段尾句与段首句形成呼应（先说→展开→再说一遍）

### P6. 模板化结构（Template Structure）

**信号：**
- 引言→定义→特点→优势→应用→挑战→展望（标准八股）
- 每节长度接近，篇幅均匀
- 无作者独特的组织方式

## 🟡 中信度模式

### P7. 加粗滥用（Boldface Overuse）

**信号：**
- 每段都有加粗词组
- 加粗的不是关键术语而是普通形容词
- "**显著提升**" / "**核心优势**" / "**关键能力**"

### P8. "通过...实现..." 句式（Through-Achieve Pattern）

**高频句式：**
- "通过引入 X 技术，实现了 Y 功能"
- "基于 X 框架，构建了 Y 系统"
- "借助 X 方法，达到了 Y 效果"

**判定标准：** 全文 3+ 次使用此句式 → 中信度

### P9. emoji 装饰（Emoji Decoration）

**信号：**
- 标题或列表项带 emoji（🚀💡✅🔥）
- 非必要场景的 emoji 使用
- 每个要点前都加 ✅ 或 🔸

### P10. 被动语态堆砌（Passive Voice Accumulation）

**信号：**
- "被广泛应用于" / "被业界视为" / "被称为"
- "可以发现" / "可以预期" / "可以认为"
- 大量无主语句

### P11. 定语堆砌（Modifier Stacking）

**信号：**
- "基于深度学习的端到端的高性能的智能化的数据处理系统"
- 一个名词前 3+ 个"的"字定语
- "的"字频率 > 5%

### P12. 虚指代词（Vague References）

**信号：**
- "这一举措" / "这一趋势" / "这一现象"
- "上述内容" / "前文所述"
- 指代不明确，读者需回溯才能理解

### P13. 递进套话（Progressive Formula）

**信号：**
- "首先...其次...最后..."
- "第一步...第二步...第三步..."
- 列举总是恰好三项

### P14. 权威暗示（Authority Hinting）

**信号：**
- "业界普遍认为" / "业内专家指出"
- "根据相关研究表明"（不引具体文献）
- "众所周知" / "不言而喻"

### P15. 均衡观点（Balanced Viewpoint）

AI 总是两面都照顾到。

**信号：**
- "虽然...但是..." 出现 3+ 次
- 每个观点后都跟一个"然而"
- "在带来机遇的同时也面临着挑战"

## 🟢 低信度模式（需组合判定）

### P16. 句式单一（Monotone Sentences）

- 全文句式结构相似
- 句子长度接近
- 缺少短句（< 10 字）和长句（> 30 字）的交替

### P17. 概念罗列（Concept Inventory）

- 大量定义性段落（"X 是一种..." / "Y 是指..."）
- 无分析，只有概念堆砌
- 读起来像术语词典

### P18. 均匀段落（Uniform Paragraphs）

- 每段字数接近（如全部 100-150 字）
- 缺少短段（1-2 句的过渡段或强调段）
- 缺少长段（深入分析的详细段落）

### P19. 无个人视角（No First Person）

- 通篇无"我认为" / "我们发现" / "在实际项目中"
- 无个人经验或判断
- 读起来像百科词条

### P20. 标准学术结尾（Academic Conclusion）

- "本文分析了...，探讨了...，提出了..."
- "未来将进一步研究..."
- 结论完全重复引言内容

### P21. 过度定义（Over-Definition）

- 对常见术语也做定义
- "所谓 X，是指..." / "X，即..."
- 定义后并不在文中使用该术语

### P22. 列表项等长（Equal-Length List Items）

- 每个列表项字数接近
- 每项结构平行（"名词+动词+形容词"）
- 缺少长短不一的自然感

### P23. 无口语化表达（No Colloquialisms）

- 全文 100% 书面语
- 无任何口语化表达或行业黑话
- 过于"正确"，缺少人味

### P24. 递归展开（Recursive Expansion）

- 概念 A 用概念 B 解释，概念 B 用概念 C 解释
- 实质上什么都没说
- "A 是指通过 B 实现 C 的过程"

## 检测流程

1. **扫描全文**，标记每个模式出现的位置
2. **统计**：命中模式数量 + 每个模式的出现次数
3. **组合判定**：
   - 5+ 个不同模式命中 → AI 生成概率极高
   - 3-4 个模式命中 → AI 生成概率较高
   - 1-2 个模式命中 → 不确定，需看上下文
   - 0 个模式命中 → 大概率人类撰写
4. **结合维度 6.2（原创思考）**：即使无 AI 痕迹，若文档无作者独到见解/判断，仍应扣分
5. **输出**：列出命中模式编号 + 原文引用 + 密度统计
